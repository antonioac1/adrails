# adsops QA - adversarial property run (invariants)
Generated by `tests/qa_invariants.py` (stdlib only, `random.Random(seed)` for seeds 1..200).
```
cd <repo root>
python3 tests/qa_invariants.py
```
## What was run
* 200 seeds x 30 steps = 6000 `tools/call` requests through `adsops.protocol.Server.handle`.
* Each seed: fresh temp config / desired-state file / policy file (`require_plan_id=true`, `max_guard_age_min=30`, `protected_terms=['core term']`, caps `{"daily_spend_pause_usd": 25, "lifetime_spend_pause_usd": 500, "max_daily_budget_usd": 20, "max_end_date": "2035-12-31", "max_ops_per_run": 10, "min_daily_budget_usd": 5}`) / plan ledger / heartbeat / fake git runner, against a simulated Google Ads account (`search`/`mutate`, applying ops only when `validate_only is False`).
* Half the seeds run with `allow_enable=false`. Random budgets (in and out of range), statuses, end dates (past / at max / beyond max), negatives (some containing `core`), clocks (+0s..+1h), spend today/lifetime, heartbeats (fresh/stale/future/missing), plan ids (fresh / reused / expired / garbage), and 12% injected `ToolError` commit failures (reconcile path).

## Notes on the checks
* Invariant 2 is evaluated per `server.handle` call, comparing the exact ops payload of each `validate_only=False` mutate against every `validate_only=True` mutate that preceded it in the same call (JSON-canonical comparison, service must match too).
* Invariant 5 uses `safety.exposure_increases()` on the union of committed ops against the simulated live state captured *before* the call, and the heartbeat mtime read after the call's setup. `require_fresh_guard` tolerates clock skew up to -5 min and a max age of 30 min, so that window is what 'fresh' means here.
* Invariant 6 is read off the plan ledger itself (`consumed` events per pid); a second acceptance would append a second `consumed` event because `PlanLedger.consume` appends only after all of its checks pass.
* Invariant 1 is checked both on the committed `amountMicros` payload and on the simulated account's budget after the call.
* Invariant 7 compares the state file's `guards` object to the original (the policy file is the only source of caps; the state file must never gain, lose or mutate them) and the policy file's sha256.
